# to-do-application-grp6
About the Project

The To-Do List App is a simple and user-friendly task management application developed using HTML, CSS, Python, and PostgreSQL. It helps users organize their daily activities by allowing them to add, view, update, and delete tasks.

The application provides an easy way to manage daily work, keep track of pending tasks, and improve productivity through better task organization.

🚀 Features

Add Tasks: Create new tasks with ease.

View Tasks: Display all added tasks in an organized manner.

Update Tasks: Edit existing tasks whenever required.

Delete Tasks: Remove tasks that are no longer needed.

Task Management: Store and manage tasks using a PostgreSQL database.

User-Friendly Interface: Simple and clean design for easy navigation.
